## Git and GitHub Fundamental
| --- | --- |
| `git init` | Git Repository စလုပ် |
| `git add` | File ကို Stage လုပ် |
| `git commit` | Snapshot သိမ်း |
| `git log` | Commit History ကြည့် |
| `git log --oneline` | Commit အတိုချုံးကြည့် |
| `git status` | Repository အခြေအနေကြည့် |
| `git checkout -b` | Branch အသစ်လုပ် |
| `git checkout` | Branch ပြောင်း |
| `git merge` | Branch ပေါင်း |
| `git branch` | Branch List ကြည့် |
| `git remote add origin` | GitHub Repository ချိတ် |
| `git push` | GitHub ကို Upload |
| `git pull` | GitHub က Download |
